# COHRS — CO Heterodyne Inner Milky Way Plane Survey

Data from the JCMT/COHRS survey (¹²CO J=3-2, 345.796 GHz) are not included in this repository.

COHRS DR2 (Park et al. 2023, ApJS 264, 16) is publicly available on CANFAR:
DOI: 10.11570/22.0078

The data directory contains:
- RELEASE2_CUBE_REBIN/  — 3D cubes rebinned to 0.635 km/s (~1.1 GB per tile)
- RELEASE2_INTEG/       — moment-0 integrated-intensity maps
- RELEASE2_LV/          — longitude-velocity diagrams
