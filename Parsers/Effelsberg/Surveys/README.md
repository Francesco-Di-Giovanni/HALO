# EBHIS — Effelsberg-Bonn HI Survey

Data from the EBHIS survey (HI 21-cm, 1.4 GHz) are not included in this repository.

Download individual profiles via the Argelander-Institut Bonn server:
https://www.astro.uni-bonn.de/hisurvey/AllSky_profiles/index.php

Use the download_ebhis.py script included in this repository to batch-download profiles.

Full EBHIS HI cubes (native resolution, 10.8 arcmin):
https://vizier.cds.unistra.fr/viz-bin/cat/J/A+A/585/A41
