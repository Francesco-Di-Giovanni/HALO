# VLASS — VLA Sky Survey

Data from the VLASS survey (3 GHz continuum) are not included in this repository.

CIRADA cutout service (programmatic download via astroquery):
https://ws.cadc-ccda.hia-iha.nrc-cnrc.gc.ca/caom2ops/sync

VLASS data portal:
https://cirada.ca/vlasscatalogueql0

NRAO VLASS homepage:
https://science.nrao.edu/vlass

Use view_vlass.py included in this repository to download and display cutouts automatically.
