# LAB — Leiden/Argentine/Bonn Survey

Data from the LAB all-sky HI survey (HI 21-cm, 1.4 GHz) are not included in this repository.

Download individual profiles via the Argelander-Institut Bonn server:
https://www.astro.uni-bonn.de/hisurvey/AllSky_profiles/index.php

Use the download_lab.py script included in this repository to batch-download profiles.
